# Инструменты P0

`compare_snapshot_trees.ps1` сравнивает два каталога с копиями пользовательских файлов сохранений. Он читает их и пишет CSV отчёт в явно заданный путь. Скрипт не изменяет входные каталоги, не распаковывает/не редактирует игровые архивы и не обращается к процессам игры.

Сравнивайте `before` и `after` одного peer раздельно. Если хотите сравнить A и B, делайте это отдельным запуском и трактуйте результаты как сравнение файлов, а не game state.
