# Диагностика

- **Игра не найдена:** выберите папку вручную. Офлайн пакетная функция доступна без игры.
- **Версия UNKNOWN:** это ожидаемо, когда версия не извлекается надёжно. До подтверждения build не создавайте marker.
- **Пакет повреждён / SHA mismatch:** остановитесь, запросите повторный ZIP; не загружайте архив с ошибкой.
- **Неверный participant ID или checkpoint ID:** отмените импорт и запросите экспорт для правильного участника/точки.
- **Файл уже существует:** программа откажется его перезаписывать. Сохраните backup и выберите отдельную папку; не удаляйте оригинал наугад.
- **Marker просрочен:** авторский loader игнорирует и удаляет marker старше 15 минут. Подготовьте новую попытку только после готовности всей группы.
- **В marker нет `players` строки:** авторский код не выполняет owner remap, если исходный mapping неизвестен. Не сочиняйте base/count.
- **Mission mismatch:** проверяется внутренний путь, а не название миссии в меню; используйте точное значение из авторского лога/эксперимента.
- **Неизвестен `archive_path`:** штатный код маркера хранит виртуальный archive base path (например, `@/profiles/<id>/save/coop_ckpt/`), а не абсолютный Windows путь к `.sav`. Возьмите точное значение из собственного runtime лога checkpoint; не выводите player/profile ID из догадки.
- **Программа завершилась:** повторный запуск не удаляет пакеты/checkpoint. Сначала запустите импорт/проверку снова; стадии копирования остаются локальными, опубликование атомарно.
- **Восстановление не работает в игре:** остановитесь, экспортируйте очищенный diagnostics JSON и сохраните исходные логи/скриншоты отдельно. Не отправляйте профиль целиком.

Вопросы о загрузчике/совместимости Coop Checkpoint направляйте автору оригинального проекта. Данный менеджер не патчит игровой процесс и не меняет `version.dll`.
