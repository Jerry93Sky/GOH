# Первый запуск V0.2.1

1. Запустите менеджер из отдельной папки; каталог игры не нужен для офлайн-проверки пакетов.
2. Укажите собственное checkpoint-хранилище вне папки игры.
3. Для сбора данных выберите нужный игровой профиль и точные логи game process; хост отдельно указывает лог local server process. Менеджер не предполагает, что их `%TEMP%` совпадают.
4. Для подготовки восстановления используйте только выбранные архивы, manifest и заполненный ручной consistency protocol. Не подставляйте runtime-поля, которых нет в источниках.
5. Участники вручную обмениваются собственными ZIP-пакетами и подтверждают готовность нового лобби. Host client marker и host server marker создаются отдельными операциями.
6. Сверяйте полный источник метаданных, архив, путь marker и preflight перед записью. При любой неоднозначности остановитесь.

Это экспериментальная подготовка файлов: игра не управляется менеджером, а успешная загрузка не подтверждена. Инструкция первого полевого запуска и формат consistency protocol находятся в [P1-C.1 field-test guide](P1_C1_FIRST_RUN_RU.md). TEST-A и TEST-B остаются `NOT_RUN`.
