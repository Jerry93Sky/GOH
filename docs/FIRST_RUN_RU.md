# Первый запуск

- Программа работает офлайн и не подключается к Steam, игровым серверам или другим участникам.
- Укажите каталог checkpoint-хранилища. Не используйте каталог игры как хранилище.
- Автопоиск проверяет несколько стандартных Steam-папок; иначе укажите путь вручную.
- Поле версии сейчас намеренно показывает `UNKNOWN`: наличие EXE не является проверкой версии и совместимости.
- Создайте файловую точку существующим coordinator по процедуре P1-A. Окно показывает manifest, статусы и целостность файлов.
- Для распределения передайте каждому участнику отдельный ZIP. Хост получает пакет с серверным архивом; гостям этот архив не нужен и не выдаётся.
- Импортируйте свой пакет в локальную папку сохранений профиля. Если файл уже существует, сначала сделайте резервную копию вручную; менеджер не перезаписывает его.
- Режим A анализирует уже существующие файлы `coop_checkpoint_reload_client.txt` и `coop_checkpoint_reload_server.txt` в Windows TEMP. Он ничего не активирует.
- Режим B доступен только с явными метаданными recovery; шаблон в `RECOVERY_METADATA_TEMPLATE_RU.json`. Не указывайте путь миссии, виртуальный archive base path или player mapping по догадке. Вызов подготовки создаёт одноразовый текстовый marker с TTL 15 минут. Это экспериментальная интеграция, не доказательство загрузки.
