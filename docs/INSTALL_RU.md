# Установка V0.1 на тестовом компьютере

1. Скачайте ZIP из GitHub Actions artifact этой ветки. После распаковки выполните в PowerShell `(Get-FileHash .\GOHRecoveryManager.exe -Algorithm SHA256).Hash.ToLower()` и сравните результат с левой колонкой `checksums.sha256`.
2. Распакуйте архив в отдельную папку, например `C:\GOH-Recovery-Test`. Запустите `GOHRecoveryManager.exe`.
3. Для работы с пакетами игра не нужна. Для обнаружения файлов укажите папку игры кнопкой «Выбрать».
4. Coop Checkpoint 1.0.4 при необходимости скачивается пользователем отдельно с [официального release автора](https://github.com/nicko996/goh-coop-mods/releases/tag/coop-checkpoint-v1.0.4). В этом пакете его DLL и `version.dll` нет.
5. Не копируйте наш EXE в каталог игры и не заменяйте `version.dll`. На тестовой копии игры следуйте штатной инструкции выбранного loader. При существующем GOHSE оставьте его loader без изменений.
6. До любых ручных изменений сохраните затрагиваемые файлы и используйте отдельный тестовый профиль. Не устанавливайте эксперимент в рабочую игру.

Удаление: закройте программу и удалите распакованную папку. Локальные checkpoint и импорты хранятся отдельно в `%LOCALAPPDATA%\GOH Coop Recovery`; удаляйте их только после ручной проверки. Установщик не меняет игровые файлы, профили или TEMP-маркеры при запуске.
