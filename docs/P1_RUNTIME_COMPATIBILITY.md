# Совместимость runtime и контрольного мода

## Найденный release

На 2026-11-23 GitHub Releases содержит Coop Checkpoint **1.0.4**, tag [`coop-checkpoint-v1.0.4`](https://github.com/nicko996/goh-coop-mods/releases/tag/coop-checkpoint-v1.0.4), asset `goh-coop-checkpoint-v1.0.4.zip`. Release notes говорят «Tested on game version 1.069.0», с GOHSE 0.1.2 и без него. [README в release tag](https://github.com/nicko996/goh-coop-mods/blob/coop-checkpoint-v1.0.4/mods/coop-checkpoint/README.md) описывает найденную механику как reverse-engineered для game v1.067.

Интерпретация: **1.069.0 — единственная версия игры, явно заявленная автором как протестированная именно release 1.0.4.** Упоминание 1.067 обозначает базу анализа, но само по себе не доказывает совместимость тега 1.0.4 с ней. Версия GoH на машине пользователя пока не установлена/не обнаружена.

Отдельная [Nexus страница](https://www.nexusmods.com/calltoarmsgatesofhellostfront/mods/25) показывает устаревший файл 1.0.1 и тест game 1.067.0; для актуальной версии следует сверять GitHub release, а не старую Nexus карточку.

## Зависимости и install constraints

- Все участники должны иметь одинаковую DLL и data mod `coop_checkpoint` включённым; источник сохраняет клиентский `coop_ckpt.sav` на каждом peer и `coop_ckpt_srv.sav` на локальном server хоста.
- Официальный zip публикуется владельцем исходного проекта и содержит `version.dll`, `binaries\x64\goh_mods\coop_checkpoint.dll`, `mods\coop_checkpoint\` и GOHSE bridge.
- При установленном GOHSE релиз прямо указывает оставить его `version.dll`, не перезаписывать её; bridge из пакета подключает мод. Без GOHSE пакет предлагает использовать собственный loader.
- **Ничего не устанавливалось из этого проекта.** Репозиторий не зеркалирует бинарный asset и не устанавливает/заменяет `version.dll`. Разрешение владельца на повторную публикацию или модификацию исходников не предполагается; в исходниках не найден отдельный LICENSE.

## Ручной порядок для TEST-A

1. Сначала сверить фактический game build на обоих ПК. Предпочтительный кандидат для автораского теста 1.0.4 — GoH 1.069.0.
2. Использовать отдельную тестовую установку/копию каталога игры и отдельные профили. Сохранить оригинальный `version.dll`, существующие mod DLL и профильные файлы в backup.
3. Игроки самостоятельно получают zip только через официальный [GitHub release](https://github.com/nicko996/goh-coop-mods/releases/tag/coop-checkpoint-v1.0.4). Не использовать случайные зеркала; не передавать asset в этот проект.
4. До распаковки посмотреть содержимое. При GOHSE не заменять его `version.dll`. При наличии другого proxy/loader остановиться и сначала выяснить совместимость на тестовой копии.
5. После ручной установки обоим игрокам включить одинаковый `coop_checkpoint` data mod в Options → Mods и проверить совпадение mod list. Сверить `goh_*checkpoint*` и loader logs в `%TEMP%`.
6. Если версия игры не 1.069.0, считать результат exploratory; не объявлять release совместимым по наличию кнопок.

Из этого проекта установочные операции не запускаются. Для TEST-A нужны два человека и ручная установка владельцем игровых копий.
